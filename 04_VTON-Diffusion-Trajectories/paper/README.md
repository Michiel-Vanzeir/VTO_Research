# VISAPP paper (SCITEPRESS template)

Upload `visapp_paper.zip` to Overleaf (New Project -> Upload Project), compiler pdfLaTeX.

- `main.tex`: preamble, title, keywords, `\ifblind` switch, section includes
- `sections/`: one file per section, each with comments on what goes there
- `references.bib`: starter references (verify before submitting)
- `figures/`: current analysis plots as placeholders (replace with vector PDFs)
- `article.cls`, `apalike.*`, `SCITEPRESS.sty`: official template files, do not edit

Template source: https://www.scitepress.org/documents/SCITEPRESS_Conference_Latex.zip
